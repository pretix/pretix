{% trans "Cancellation Rules" %}

{% blocktrans trimmed %} Cancellation rules allow you finegrained control about the scenarios in which it is possible to cancel orders and the fees associated with that cancellation. A process cancellation rule regulates whether a cancellation can be performed at all, depending on conditions like the event timeline. A position cancellation rule regulates which products and variations can be canceled. When a customer wants to cancel their order, all position and process rules are evaluated at that point in time. If at least one process and one position rule allow for cancellation, then the cancellation is possible. If multiple rules of one type allow for cancellation, then the one with the cheaper overall resulting fees will be used. {% endblocktrans %}
